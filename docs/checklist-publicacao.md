# Checklist de publicação

- [ ] Fazer backup do repositório atual.
- [ ] Extrair este pacote na raiz do repositório, preservando `.github/`.
- [ ] Confirmar que `index.html` está na raiz.
- [ ] Confirmar que os arquivos usados em `imgs/` existem.
- [ ] Conferir o README no preview do GitHub.
- [ ] Ativar GitHub Pages na branch `main`, pasta `/ (root)`.
- [ ] Testar em celular: navegação, botões, contraste e rolagem.
- [ ] Testar com teclado: Tab, Enter, Escape e foco visível.
- [ ] Testar efeitos ON/OFF e preferência por movimento reduzido.
- [ ] Conferir favicon e prévia de compartilhamento.
- [ ] Aguardar o deploy de Pages terminar e abrir a URL publicada.
