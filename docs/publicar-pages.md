# Publicar a experiência REI no GitHub Pages

1. Envie os arquivos deste pacote para a raiz do repositório `reinaldo31wjm`.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)` e salve.
5. Aguarde a publicação. O endereço esperado é `https://reinaldo31wjm.github.io/reinaldo31wjm/`.

O `index.html` é a página interativa; o `readme.md` continua sendo a apresentação exibida no repositório. O JavaScript não precisa de bibliotecas externas.
