# validação antes da publicação

## verificações automatizadas concluídas

- [x] Sintaxe do JavaScript inline.
- [x] Referências locais do HTML/CSS e âncoras internas.
- [x] IDs duplicados.
- [x] Links relativos do Markdown.
- [x] Decodificação de imagens rasterizadas e leitura de SVG como XML.
- [x] Nomes de arquivos em minúsculas.
- [x] Integridade do ZIP final.

## verificações manuais pendentes após publicação

- [ ] Abrir a página em um navegador atualizado.
- [ ] Confirmar banner, avatar, favicon e imagens animadas.
- [ ] Testar os links externos e o deploy do GitHub Pages.
- [ ] Testar em tela estreita e monitor grande.
- [ ] Testar navegação com Tab, Shift+Tab, Enter e Escape.
- [ ] Ativar movimento reduzido e economia de dados.
- [ ] Conferir o console do navegador e o comportamento visual real.

## estrutura

`index.html` é a experiência interativa. `readme.md` é a apresentação principal. Os guias e registros técnicos ficam em `docs/`; as descrições técnicas não são adicionadas ao README principal.
