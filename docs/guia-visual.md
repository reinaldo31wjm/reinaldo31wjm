# Guia visual — REI

## Direção visual

- **Conceito:** fantasia medieval sombria, com o cavaleiro como figura central.
- **Paleta:** preto carvão, vermelho escarlate e cinza claro.
- **Hierarquia:** banner principal → apresentação curta → tecnologias → estatísticas → contribuições.
- **Movimento:** manter o banner e o avatar animados; evitar empilhar vários GIFs grandes na mesma tela.
- **Espaço:** usar divisores apenas onde ajudam a separar seções. Evitar fileiras longas de selos e frases repetidas.

## Personalização

1. Edite a apresentação para refletir seus objetivos reais.
2. Ajuste as tecnologias conforme as ferramentas que você utiliza.
3. Preserve os nomes dos arquivos em `imgs/` ou atualize os caminhos no `readme.md`.
4. A cobra de contribuições só aparece depois que o workflow publica os SVGs na branch `output`.
