# Publicar a versão refinada

1. Baixe e extraia este pacote.
2. Envie o conteúdo da pasta `reinaldo31wjm-main` para a raiz do repositório `reinaldo31wjm/reinaldo31wjm`, substituindo os arquivos correspondentes.
3. Confirme que `readme.md`, `imgs/` e `.github/workflows/snake.yml` ficaram na raiz correta.
4. Abra **Actions** no GitHub e execute manualmente o workflow de animação de contribuições.
5. Quando a execução terminar com sucesso, confira se a branch `output` foi criada e se o README mostra a animação.

## Se algo não aparecer

- O banner, avatar e rodapé usam arquivos locais de `imgs/`; confira se todos foram enviados.
- A cobra depende do workflow e da branch `output`; ela pode não aparecer antes da primeira execução bem-sucedida.
- As estatísticas são imagens externas e podem demorar ou ficar temporariamente indisponíveis.
